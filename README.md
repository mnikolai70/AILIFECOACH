# Waypoint — AI Life Coach site

## What's in here
- `index.html` — the full site (bilingual EN/ΕΛ, toggle in the top nav)
- `assets/` — your six photos, already wired into the page

## Publish it on GitHub Pages
1. In your `AILIFECOACH` repo, delete the old files (or make a new repo).
2. Upload `index.html` and the `assets/` folder to the root of the repo.
3. Go to **Settings → Pages**, set source to the `main` branch, root folder.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Before you publish — one thing to finish
**Testimonials** — the 10 testimonials on the site are illustrative placeholders I wrote to show the tone and format. Swap them for real client testimonials (with permission) before publishing, the same way you'd replace stock photos.

The ElevenLabs widget is already wired up with your agent ID.

## Editing text later
Every piece of text has two versions in the HTML: `data-en="..."` and `data-el="..."`. Edit both if you change the copy, so the language toggle stays in sync.
